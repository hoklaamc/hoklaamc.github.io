## Development Commands

- `pnpm dev` - Start development server on port 3001
- `pnpm build` - Build the application for production
- `pnpm typecheck` - Run TypeScript type checking
- `pnpm serve` - Preview production build locally
- `pnpm start` - Alternative command to start development server

## Architecture

This is a React-based personal website/portfolio built with:

- **React 19** with TypeScript
- **TanStack Router** for file-based routing with type-safe navigation
- **Vite** as the build tool and dev server
- **pnpm** as the package manager (version 10.1.0+)

### Project Structure

- `src/main.tsx` - Application entry point that sets up TanStack Router
- `src/routes/__root.tsx` - Root layout component with navigation and devtools
- `src/routes/` - File-based routing directory (index.tsx, about.tsx)
- `src/routeTree.gen.ts` - Auto-generated route tree (don't edit manually)
- `src/components/` - Reusable components (NavLink.tsx)

### Key Architecture Details

The application uses TanStack Router's file-based routing system with automatic route tree generation. The router is configured with `defaultPreload: 'intent'` for performance optimization.

The root layout includes conditional rendering of TanStack Router DevTools in development mode only.

Route components are created using `createRootRoute()` and `createFileRoute()` functions from TanStack Router.

## TypeScript Configuration

TypeScript is configured with strict mode enabled and modern ES module settings. The build uses Vite's bundler module resolution.

## Development Notes

- Router devtools only appear in development builds
- Route tree is auto-generated by the TanStack Router Vite plugin
- Uses React 19's modern JSX transform
